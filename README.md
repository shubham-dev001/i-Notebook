# iNotebook 📝

A secure full-stack notes application where users can create, update, and delete personal notes with JWT authentication. Users can safely store and manage their notes anytime.

## ⚙️ Installation

### Clone the Repository
git clone https://github.com/shubham-dev001/i-Notebook.git

---

## Install Dependencies

### Frontend
npm install

### Backend
cd backend
npm install

---

## ▶️ Run the Project

### Start Backend
nodemon index.js

### Start Frontend
npm start

---

## 🔑 Environment Variables

Create a .env file inside backend folder:

MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
